## Getting started with Haptiq BMAD

New here? Run `haptiq-bmad-help` — it lists every installed Haptiq command, grouped into the
order they are normally run. Pass it a command name (e.g. `haptiq-bmad-help <command>`) to see
what runs before and after that one.

Then activate the agent for your role and pick an item from its menu:

/haptiq-bmad-ba-business-analyst — Business Analyst Agent, Business Analyst
/haptiq-bmad-design-architect — Amol, Design Architect
/haptiq-bmad-dev-be-engineer — Haptiq-developer, Backend Engineer
/haptiq-bmad-dev-fe-engineer — Wayne, Frontend Engineer
/haptiq-bmad-devops-architect — Architect Agent, DevOps Architect
/haptiq-bmad-devops-compliance-auditor — Compliance Auditor Agent, Compliance Auditor
/haptiq-bmad-devops-engineer — DevOps Engineer Agent, DevOps Engineer
/haptiq-bmad-devops-sre-responder — SRE Responder Agent, SRE Responder
/haptiq-bmad-pdm-product-manager — Product Manager Agent, Product Manager
/haptiq-bmad-pdm-tech-manager — Engineering Manager Agent, Engineering Manager / Technical Manager
/haptiq-bmad-qa-engineer — Tara, QA Engineer

Each role's own walkthrough is at `_bmad/haptiq-<role>/docs/quickstart.md`.
