## Getting started with h BMAD

New here? Run `h-bmad-help` — it lists every installed h command, grouped into the
order they are normally run. Pass it a command name (e.g. `h-bmad-help <command>`) to see
what runs before and after that one.

Then activate the agent for your role and pick an item from its menu:

/h-bmad-ba-business-analyst — Business Analyst Agent, Business Analyst
/h-bmad-design-architect — Amol, Design Architect
/h-bmad-dev-be-engineer — h-developer, Backend Engineer
/h-bmad-dev-fe-engineer — Wayne, Frontend Engineer
/h-bmad-devops-architect — Architect Agent, DevOps Architect
/h-bmad-devops-compliance-auditor — Compliance Auditor Agent, Compliance Auditor
/h-bmad-devops-engineer — DevOps Engineer Agent, DevOps Engineer
/h-bmad-devops-sre-responder — SRE Responder Agent, SRE Responder
/h-bmad-pdm-product-manager — Product Manager Agent, Product Manager
/h-bmad-pdm-tech-manager — Engineering Manager Agent, Engineering Manager / Technical Manager
/h-bmad-qa-engineer — Tara, QA Engineer

Each role's own walkthrough is at `_bmad/h-<role>/docs/quickstart.md`.
